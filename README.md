# aaadlander
Voor dit project moesten we een webapplicatie bouwen waarmee je een rover kunt besturen. De opdracht bestond uit de volgende onderdelen: 
# Features
Besturing met WASD: de rover kan met de toetsen W, A, S en D vooruit, achteruit, links en rechts bewegen.
Live camerabeeld:op de rover zit een camera waarmee je live kunt zien waar de rover rijdt.Helling- en rollmeting:
een sensor op de rover meet de helling (pitch) en roll, en deze waarden worden live weergegeven in de webapplicatie.

 de front-end is gemaakt via Html css en de sensordata vanaf de arduino is via note red binnengekomen en doormidden van een api weergegeven in de aplicatie.
